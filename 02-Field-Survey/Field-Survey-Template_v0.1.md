## D. Tree baseline procedure

สำหรับแต่ละตำแหน่ง:

1. ยืนยัน Farm/Zone/Row/Tree sequence
2. ติดป้ายชั่วคราวหรือป้าย Field Validation
3. สแกน/กรอกรหัสและตรวจไม่ซ้ำ
4. บันทึกพันธุ์และปีปลูก โดยระบุ `confirmed`/`estimated`/`unknown`
5. วัดลำต้น ณ จุดวัดมาตรฐานที่ตกลงกัน
6. วัดทรงพุ่ม 2 ทิศและความสูงตามวิธีที่ตกลง
7. บันทึกสถานะสุขภาพและอาการที่สังเกต ไม่วินิจฉัยถ้าไม่มีผู้รับผิดชอบ
8. ถ่ายรูปตามมุมมาตรฐาน
9. บันทึก GPS 2–3 ครั้งถ้าต้องการใช้เป็นตำแหน่งช่วยนำทาง

| Scenario | เวลาเริ่ม–จบ | พบต้นถูก | สแกนถูก | ส่งงานสำเร็จ | ต้องช่วยกี่ครั้ง | หมายเหตุ |
|---|---|---|---|---|---:|---|
| งานรายต้น | | | | | | |
| สแกนผิดต้น | | | | | | |
| งานรายกลุ่มมี exception | | | | | | |

คำถามหลังทดสอบ:

- ข้อความใดอ่านไม่เข้าใจ
- ปุ่มใดหาไม่เจอ
